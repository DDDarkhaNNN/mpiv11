MPI бағдарламасы қалай жұмыс істейді?

Message Passing Interface (MPI) — үлестірілген жады бар жүйелерге арналған хабар алмасу стандарты. Бір ғана бағдарлама K тәуелсіз процесс ретінде қатар іске қосылады (mpiexec -n K prog.exe): әр процестің өз жады және 0…K−1 аралығындағы бірегей рангы болады.

M1

1. Ранг және инициализация

Кез келген MPI шақырулары MPI_Init пен MPI_Finalize арасында орындалады. MPI_COMM_WORLD коммуникаторы барлық іске қосылған K процесті біріктіреді; P0 әдетте негізгі (бас) процесс рөлін атқарады.

MPI_Comm_size(MPI_Comm comm, int *size)MPI_Comm_rank(MPI_Comm comm, int *rank)
MPI_Init(&argc, &argv);
int rank, size;
MPI_Comm_rank(MPI_COMM_WORLD, &rank); // 0 .. K-1
MPI_Comm_size(MPI_COMM_WORLD, &size); // K
MPI_Finalize();

M2

2. Екі процесс арасында хабар алмасу

Жіберуші буферді, элементтер санын, типті (MPI_INT, MPI_DOUBLE), қабылдаушы рангын және msgtag тегін көрсетеді. MPI_ANY_SOURCE пен MPI_ANY_TAG кез келген жіберушіден немесе тегпен қабылдауға, ал MPI_Probe хабар өлшемін алдын ала білуге мүмкіндік береді.

MPI_Send(buf, count, type, dest, tag, comm)MPI_Recv(buf, count, type, source, tag, comm, &status)MPI_Sendrecv(sbuf, scnt, stype, dest, stag, rbuf, rcnt, rtype, src, rtag, comm, &st)
MPI_Status st;
MPI_Probe(src, MPI_ANY_TAG, MPI_COMM_WORLD, &st);
int count;
MPI_Get_count(&st, MPI_INT, &count);
MPI_Recv(buf, count, MPI_INT, st.MPI_SOURCE, st.MPI_TAG, MPI_COMM_WORLD, &st);

M3

3. Редукция, туынды типтер және орау

Редукция операциялары (MPI_SUM, MPI_PROD, MPI_MAX, MPI_MIN) барлық процестегі массив элементтерін позиция бойынша біріктіреді. Әртекті деректерді (мысалы, int–double–int) бір хабармен жіберу үшін құрылымдық тип (MPI_Type_create_struct) немесе буферге орау (MPI_Pack / MPI_Unpack) қолданылады.

MPI_Reduce(sbuf, rbuf, count, type, op, root, comm)MPI_Allreduce(sbuf, rbuf, count, type, op, comm) · MPI_Scan(...)MPI_Type_create_struct(...) · MPI_Pack(...) / MPI_Unpack(...)
MPI_Reduce(local.data(), sum.data(), k + 5, MPI_INT, MPI_SUM, 0, comm);
MPI_Scan(local.data(), prefMax.data(), k + 5, MPI_INT, MPI_MAX, comm);

M4

4. Ұжымдық жіберу және коммуникаторлар

Ұжымдық функциялар коммуникатордағы барлық процестен бір уақытта шақырылады: Bcast (тарату), Gather/Gatherv (жинау), Scatter/Scatterv (үлестіру), Allgather, Alltoall/Alltoallv. Ал MPI_Comm_create және MPI_Comm_split ішкі процестер топтарына жеке коммуникатор құрады (color = MPI_UNDEFINED болса процесс топқа кірмейді).

MPI_Bcast(buf, count, type, root, comm)MPI_Gatherv / MPI_Scatterv / MPI_Allgather / MPI_AlltoallvMPI_Comm_split(comm, color, key, &subcomm)
int color = (n == 1) ? 0 : MPI_UNDEFINED;
MPI_Comm sub;
MPI_Comm_split(MPI_COMM_WORLD, color, rank, &sub);
if (sub != MPI_COMM_NULL) {
    MPI_Allgather(&a, 1, MPI_DOUBLE, res.data(), 1, MPI_DOUBLE, sub);
    MPI_Comm_free(&sub);
}

M5

5. Виртуалды топологиялар: торлар мен графтар

MPI_Cart_create процестерді 2D/3D декарттық торға (периодты немесе периодсыз) орналастырады; MPI_Cart_sub торды ішкі жолдарға не матрица қималарына бөледі; MPI_Cart_shift көрші рангтарды табады. Еркін байланыстар үшін MPI_Graph_create граф топологиясы қолданылады.

MPI_Cart_create(comm, ndims, dims, periods, reorder, &cart)MPI_Cart_coords · MPI_Cart_rank · MPI_Cart_sub · MPI_Cart_shiftMPI_Graph_create(comm, nnodes, index, edges, reorder, &graph)
int dims[2] = {2, size / 2}, periods[2] = {0, 1};
MPI_Comm cart;
MPI_Cart_create(MPI_COMM_WORLD, 2, dims, periods, 0, &cart);
int src, dst;
MPI_Cart_shift(cart, 1, 1, &src, &dst); // жол бойынша +1 жылжу
