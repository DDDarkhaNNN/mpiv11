Модуль 2 • Вариант 11 • MPI

Распакуйте всю папку. В адресной строке Проводника внутри неё введите cmd и нажмите Enter. В открывшемся окне введите номер задачи, например 24, или полное имя MPIBegin24.

Первая строка — общее число процессов вместе с рангом 0. Дальше программа сама подписывает каждый ранг и запрашивает только его данные. Каждый ответ вводите отдельной строкой. Для набора перечислите числа через пробел. Целое число записывайте без точки (2), вещественное — с точкой и цифрами по обе стороны (2.0). При ошибке программа покажет номер числа и попросит повторить строку. Длина набора определяется автоматически. Для выхода введите -1 в ответ на вопрос о количестве процессов или q на любой строке.

Соответствие практикуму Абрамяна
Издание 2011 года: состав варианта на стр. 29, условия на стр. 68–71. Условия на сайте автора: https://ptaskbook.com/ru/ptformpi/mpibegin.php

10. Каждый отправитель одним MPI_Bsend посылает 1–4 целых числа. Главный принимает от рангов 1, 2 и далее и получает фактическую длину через MPI_Get_count. Наборы [2, 4] и [7, 5, 4, 2] дают ответ 2 4 7 5 4 2.
11. На шаге r главный вызывает MPI_Send для r-го числа с адресатом r. Три числа 1.5, -2, 4.25 получат ранги 1, 2, 3 соответственно.
16. Каждый подчинённый ранг отправляет число только при N > 0. Главный принимает заданное число сообщений с MPI_ANY_SOURCE. Для -3, 5, 0, 7 при двух положительных числах сумма равна 12.
18. MPI_Send передаёт исходное число следующему рангу, MPI_Recv получает от предыдущего. Для 10, 20, 30, 40 ответ по рангам равен 40, 10, 20, 30. Ранг 0 начинает с отправки, остальные — с приёма, поэтому кольцо не блокируется.
21. Адресаты образуют перестановку. Каждый MPI_Recv с MPI_ANY_SOURCE принимает единственное адресованное ему число, а MPI_SOURCE указывает отправителя. Если адресат выше собственного ранга, процесс сначала отправляет, иначе сначала принимает. Этот порядок согласуется с убыванием адреса назначения, поэтому обмены могут завершиться. Для пересылки самому себе блокирующий приём выполняет второй поток того же MPI-процесса. При A=[1.5, 2.5, 3.5] и N=[2, 0, 1] ответы по рангам: (2.5, 1), (3.5, 2), (1.5, 0).
24. Попарный MPI_Sendrecv меняет наборы рангов 0 и 1, 2 и 3 и т. д. При отправке [1.5] и [8, -2.5, 4] ранг 0 получит все три числа, а ранг 1 — только 1.5.
26. Отправитель помещает номер N в тег MPI_Send. Главный указывает очередной тег в MPI_Recv, поэтому выводит числа по номеру N. Для пар (4.5, 3), (-1, 1), (8.25, 2) ответ равен -1 8.25 4.5.
29. Отправитель кодирует тип в теге MPI_Send. Главный вызывает MPI_Probe с MPI_ANY_TAG для каждого ранга и выбирает MPI_INT или MPI_DOUBLE по тегу. Для целых [8, -3] от ранга 1 и вещественных [2.5] от ранга 2 ответ равен 8 -3 2.5.

Для запуска готовых EXE нужен MPI с mpiexec.exe в PATH. Для пересборки откройте папку в VS Code и выполните build.cmd в CMD. Для сборки требуются 64-разрядный g++ с C++17 и MPI SDK.
