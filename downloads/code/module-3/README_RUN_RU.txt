Модуль 3. Вариант 11. Ручной ввод в CMD

Откройте распакованную папку в Проводнике. В адресной строке наберите cmd и нажмите Enter.
Введите номер задачи. Когда появится вопрос о количестве процессов, введите число K (включая процесс ранга 0).
Программа подскажет, какие числа ввести и для какого ранга. Вводите одну строку за раз. Дробную часть отделяйте точкой.
После вывода ответа можно ввести новое K для той же задачи. Чтобы вернуться в CMD, введите -1 на вопрос о количестве процессов или q на любой строке.
Ниже приведены примеры ручного ввода. Первое число каждого примера — команда для запуска задачи, второе — число процессов.
