МОДУЛЬ 5 · ВАРИАНТ 11 · VS CODE И CMD

Задачи по практикуму Абрамяна: модуль 5, вариант 11 (стр. 65); полные условия — в приложении, стр. 78–83.
Номера задач: 83, 85, 92, 94, 96, 100.

Откройте всю папку «Module 5 Variant 11» в синем VS Code. Терминал → Новый терминал откроет CMD в этой папке. Введите номер задачи, например 96, или run 96, или MPIBegin96.exe.
Сначала введите общее количество процессов K (включая ранг 0), затем данные по подсказкам. Каждую строку завершайте Enter. Целое число вводите без точки: 2. Вещественное — с точкой и цифрами по обе стороны: 2.0. Если введён неверный тип, программа покажет номер числа и попросит повторить строку.
После ответа можно ввести новое K; -1 на вопросе о K или q на любой строке завершает программу. Строки ответа разных MPI-процессов могут появиться в разной очередности; ориентируйтесь на «Ответ ранга R».

ОГРАНИЧЕНИЯ ПО ЧИСЛУ ПРОЦЕССОВ
83: K делится на N, которое вводится после K; N > 1.
85 и 96: K чётно, K ≥ 4.
92: K равно 8 или 12.
94: M·N ≤ K, M > 0, N > 0.
100: K равно 7, 10 или 13.

Для запуска готовых EXE нужен Microsoft MPI с mpiexec.exe в PATH. Для пересборки выполните build.cmd; требуются g++ C++17 и Microsoft MPI SDK.

ЗАДАЧИ И ПРИМЕРЫ
Первое число каждого примера — K. Остальные строки вводятся по подсказкам.

MPIBegin83 — главный вводит N; MPI_Bcast передаёт его всем. MPI_Cart_create строит матрицу N × K/N без изменения рангов. MPI_Cart_coords даёт координаты каждого ранга.
