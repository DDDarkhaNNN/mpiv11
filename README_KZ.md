# MPI Lab · 11-нұсқа

Сайт: https://dddarkhannn.github.io/mpiv11/

Репозиторий: https://github.com/DDDarkhaNNN/mpiv11

Бұл оқу сайты М. Э. Абрамян практикумындағы 11-нұсқаның 1–5 модульдегі барлық 36 `MPIBegin` есебін көрсетеді. Есептің шарты, мәндерді енгізу, нәтиже, қадамдық сызба және C++ коды бөлек қойындыларда берілген. Интерфейс қазақша және орысша.

## Жұмыс істеу тәсілі

- **Браузердегі есептеу** MPI операциясының нәтижесін JavaScript арқылы дәл модельдейді және EXE бағдарламаларындағыдай қатаң тип тексеруін қолданады: бүтін сандар нүктесіз (`2`), ал нақты сандар нүктемен және екі жағындағы цифрлармен (`2.0`) жазылады.
- **Модуль 2, 3, 4 және 5 архивтері** нақты MPI бағдарламаларын қамтиды (барлығы 34 есеп): әр тапсырманың `.cpp`, `.exe`, `.cmd` файлдары, ортақ `console_mpi.hpp`, `build.cmd` және `README_RUN_RU.txt`.
- Дайын EXE файлдарын іске қосу үшін MPI Runtime керек. Қайта құрастыру үшін MPI SDK және C++17 қолдайтын 64-биттік `g++` қажет.
- Модуль 1-дегі C++ файлдары (`MPIBegin3`, `MPIBegin5`) — MPI-сіз оқу үлгілері.

## Қолдану

1. [Практикумды](practice.html) ашып, модульді (1–5) және `MPIBegin` есебін таңдаңыз.
2. «Шарты» бөлімінде кітапқа сәйкес тапсырманы және берілген файлдағы мысалды оқыңыз.
3. «Есептеу» бөлімінде процес саны мен мәндерді енгізіңіз. «Файлдағы мысалды жүктеу» батырмасы бастапқы үлгіні қайта қояды.
4. «Нәтижені есептеу» батырмасын басыңыз. «Қадамдар» бөлімінде деректер, коммуникаторлар және виртуалды топологиялар сызбасын қараңыз.
5. «C++ коды» бөлімінде нақты MPI бастапқы кодын немесе толық модуль ZIP архивін жүктеңіз.

## Жергілікті іске қосу және тексеру

`START_SITE.bat` браузерде жергілікті сайтты ашады. Не болмаса репозиторий түбінде `python -m http.server 8765` командасын орындап, `http://127.0.0.1:8765/` мекенжайын ашыңыз.

`node tools/check-mpi-programs.mjs` барлық 34 MPI есебінің дайын EXE нәтижесін берілген мысалдармен салыстырады.
