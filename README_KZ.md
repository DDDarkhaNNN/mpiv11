# MPI Lab — оқу қолданбасы

Сайт: https://aluakasdarkhan7.github.io/mpiv11/

Репозиторий: https://github.com/aluakasdarkhan7/mpiv11

## Іске қосу

Осы бумадағы `START_SITE.bat` файлын екі рет басыңыз. Оқу қолданбасы әдепкі браузерде ашылады. Практикум PDF-і `downloads` ішінде берілген. Microsoft MPI батырмасы ресми Microsoft жүктеу бетіне апарады.

## Файл құрылымы

- `index.html` — басты бет және бөлімдерге өту;
- `practice.html` — модульдер, тапсырмалар, калькулятор және нәтижелер;
- `theory.html` — MPI теориясы;
- `resources.html` — практикум кітабы мен Microsoft MPI жүктеу сілтемесі;
- `styles/design.css` — бірыңғай дизайн жүйесі, оқуға ыңғайлы rem қаріптері және мобильді орналасу;
- `styles/reference.css` — үлгіге негізделген интерфейс: ақ бүйір мәзір, көк басқару элементтері және енгізу/нәтиже панельдері;
- `scripts/task-data.js` — модульдер мен тапсырма каталогы;
- `scripts/app.js` — есептеу логикасы, формалар және нәтижелер интерфейсі;
- `scripts/localization.js` — қазақша/орысша интерфейс;
- `scripts/lesson-data.js` — кітапқа негізделген шарттар, мысалдар және бет нөмірлері;
- `scripts/lesson-engine.js` — енгізілген мәндер бойынша қадамдарды есептеу;
- `scripts/lesson-ui.js` — қойындылар, сызба, анимация және орындалу белгілері;
- `scripts/source-code.js` — интернетсіз ашылатын C++ кодтар каталогы;
- `styles/lesson.css` — есеп қойындылары мен анимацияның стилі;
- `downloads/code/` — 19 MPI-сіз C++ файлы;
- `downloads/praktikum.pdf` — кітап файлы.

## Мүмкіндіктер

- Қазақша және орысша интерфейс;
- 1–3 модульдегі 19 интерактивті MPI есебі;
- тапсырманы іздеу, процестер санын баптау, деректерді енгізу және нәтижені көшіру;
- әр есепте «Шарты», «Есептеу», «Қадамдар», «C++ коды» қойындылары;
- өз мәндеріңізбен қадамдық түсіндіру, дерек қозғалысының сызбасы, ойнату/тоқтату және алға/артқа басқару;
- браузерде орындалу белгілерін сақтау (сақтау бұғатталса, осы сессияда ғана);
- ішіне салынған практикум кітабы және Microsoft MPI ресми жүктеу сілтемесі.

Есептеу браузер ішінде модельденеді. Нақты параллель MPI орындалуы үшін Microsoft MPI-ді бөлек орнату керек.

## Қолдану

1. Практикумнан модуль мен MPIBegin есебін таңдаңыз.
2. «Шарты» қойындысында берілгенін, талаптарын және мысалын оқыңыз. Кітап бетіне тікелей сілтеме бар.
3. «Есептеу» қойындысында 2–12 процесті таңдап, деректерді енгізіңіз. Бөлшек сан үшін нүкте пайдаланыңыз; жиын сандарын бос орынмен бөліңіз.
4. «Есептеу» батырмасын басып, нәтижені қараңыз. «Қадамдар» қойындысында дәл осы деректердің өңделуін көріңіз.
5. Қажет болса, есепті орындалды деп белгілеңіз немесе «C++ коды» қойындысынан файлды жүктеңіз.

Шарттар берілген кітаптың 68–76-беттері бойынша қайта баяндалған; мысалдар түсіндіру үшін қосылған. MPIBegin16-дағы кітаптың K айнымалысы оң мәндер санына қатысты — сайт бұл санды автоматты анықтайды.

Сызба хабар алмасудың логикасын түсіндіреді, MPI кітапханасының нақты желілік алгоритмін немесе уақытын көрсетпейді. Жүктелетін C++ файлдары Windows үшін бұрын берілген MPI-сіз оқу үлгілері. Оларды бұл жаңартуда қайта компиляциялау орындалған жоқ. Жүйеде қозғалысты азайту қосылған болса, анимация өшіп, қолмен қадамдау қалады.

Жергілікті тексеру: 19 есептің эталондық нәтижелері, 13 қате енгізу жағдайы, 19 код файлының сәйкестігі және жергілікті сілтемелер тексерілді. Chrome ішінде қойындылар, қадамға өту, кодты көру және қазақша/орысша ауысу тексерілді. Барлық экран өлшемдеріне толық визуалдық тексеріс жүргізілген жоқ.
