# MPI Lab · 11-нұсқа

Сайт: https://aluakasdarkhan7.github.io/mpiv11/

Бұл оқу сайты 1–3 модульдегі 19 MPIBegin есебін көрсетеді. Есептің шарты, мәндерді енгізу, нәтиже, қадамдық сызба және C++ коды бөлек қойындыларда. Интерфейс қазақша және орысша.

## Жұмыс істеу тәсілі

- **Браузердегі есептеу** MPI операциясының нәтижесін JavaScript арқылы модельдейді. Ол нақты параллель процестерді іске қоспайды.
- **Модуль 2 және 3 архивтері** берілген жаңа қалталардағы нақты Microsoft MPI бағдарламаларын қамтиды: әр тапсырманың `.cpp`, `.exe`, `.cmd` файлдары, ортақ `console_mpi.hpp`, `build.cmd` және `README_RUN_RU.txt`.
- Дайын EXE файлдарын іске қосу үшін Microsoft MPI Runtime керек. Қайта құрастыру үшін Microsoft MPI SDK және C++17 қолдайтын 64-биттік `g++` қажет.
- Модуль 1-дегі C++ файлдары бұрынғы MPI-сіз оқу үлгілері.

## Қолдану

1. [Практикумды](practice.html) ашып, модуль мен MPIBegin есебін таңдаңыз.
2. «Шарты» бөлімінде тапсырманы және берілген файлдағы мысалды оқыңыз.
3. «Есептеу» бөлімінде процес саны мен мәндерді енгізіңіз. «Файлдағы мысалды жүктеу» батырмасы бастапқы үлгіні қайта қояды.
4. «Нәтижені есептеу» батырмасын басыңыз. «Қадамдар» бөлімінде деректер қозғалысын қараңыз.
5. «C++ коды» бөлімінде нақты MPI бастапқы кодын немесе толық модуль ZIP архивін жүктеңіз.

## Жергілікті іске қосу және тексеру

`START_SITE.bat` браузерде жергілікті сайтты ашады. Не болмаса репозиторий түбінде `python -m http.server 8765` командасын орындап, `http://127.0.0.1:8765/` мекенжайын ашыңыз.

Берілген ортада екі модульдің `build.cmd` скрипті сәтті орындалды. `node tools/check-mpi-programs.mjs` барлық 17 есептің дайын EXE нәтижесін берілген мысалдармен салыстырады. Браузерде осы 17 есептің үлгісі, тіл ауыстыру, шарт, код және жүктеу сілтемелері тексерілді.
